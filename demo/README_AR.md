# قاعدة عرض تك فلو

الملف `techflow-egypt-demo.sqlite` قاعدة عرض مستقلة وجاهزة لمحل إلكترونيات مصري. لا تُفتح تلقائيًا ولا تُستخدم عند إنشاء شركة جديدة؛ لذلك تظل أي قاعدة عميل جديدة فارغة.

## فتح قاعدة العرض

1. انسخ `techflow-egypt-demo.sqlite` إلى مكان ثابت على جهاز Windows.
2. افتح Techflow واختر **Open Existing File / فتح ملف موجود** من شاشة اختيار الشركة.
3. اختر ملف قاعدة العرض. اسم الشركة داخلها: **تك فلو للإلكترونيات**.

احتفظ بنسخة أصلية من الملف لإعادة العرض إلى حالته الأولى بعد أي تجربة.

## إعادة إنشائها من المصدر

```bash
yarn demo:seed
yarn demo:transactions
yarn demo:test
```

الأوامر تستخدم خدمات ونماذج التطبيق ولا تكتب بيانات أعمال بـSQL مباشر. الأمر الأول يرفض الكتابة فوق قاعدة موجودة لتجنب فقدان البيانات. احذف ملف العرض بنفسك فقط عندما تريد إعادة إنشائه عمدًا.

## محتوى العرض

- EGP و`ar-EG` وسنة مالية حالية.
- مخزنان، 4 وسائل دفع عربية، ضريبة 14% وخيار 0%.
- 5 موردين، 15 عميلًا، 43 صنفًا، و108 سيريالات.
- 12 فاتورة شراء و12 استلامًا.
- 60 عملية بيع أساسية، 4 مرتجعات، وفاتورة من عرض سعر.
- دفع كاش/فيزا/تحويل/انستاباي، دفع مقسّم، بيع آجل، ودفعات جزئية.
- 3 تحويلات مخزون، حركتا تسوية، 3 عروض أسعار، و3 ورديات POS.

## القيود المعروفة والتحقق اليدوي

- التطبيق الحالي لا يحتوي نموذج مستخدمين وصلاحيات، لذلك لم تُنشأ أدوار مدير/كاشير/فني.
- نموذج حركة المخزون لا يحتوي حقل سبب؛ حركتا الفقد والتصحيح موجودتان لكن لا يمكن حفظ وصف سبب منظم دون تغيير أوسع للمخطط.
- يلزم طباعة ملصق 50×30 مم على طابعة 203 DPI ومسحه بقارئ فعلي. المقاس الناتج 400×240 بكسل، أي 50.05×30.03 مم.
- يلزم فتح الشاشات على Windows لفحص RTL بصريًا. تحقق الاختبار الآلي من `ar-EG` وRTL والترجمات، لكنه لا يستبدل الفحص البصري.

نتيجة التشغيل الأخيرة موجودة في `TEST_REPORT_AR.md`.
